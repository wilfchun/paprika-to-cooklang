# Paprika to Cooklang Converter

A utility to batch convert [Paprika 3](https://www.paprikaapp.com/) recipe exports into [Cooklang](https://cooklang.org/) files.

Designed for use with **devenv** for reproducible execution.

## Usage

### Prerequisites

- [Nix](https://nixos.org/download/) installed.
- [devenv](https://devenv.sh/) installed.

### Running

1. Clone this repository.
2. Enter the shell:
   ```bash
   devenv shell
   # Or if you use direnv:
   direnv allow
   ```
